# UART Universal Console Tool – PS2 / PS3 / PS4 / PS5

**UART Universal Console Tool** est un logiciel de diagnostic conçu pour faciliter la communication UART avec les consoles Sony PlayStation, de la PS2 à la PS5.

L'objectif est de réunir dans une seule interface simple plusieurs fonctions utiles aux techniciens, réparateurs et passionnés de réparation de consoles.

## Fonctionnalités

- Détection des ports COM disponibles.
- Configuration du port série : baudrate, bits de données, parité et bits d'arrêt.
- Communication UART en ASCII et HEX.
- Affichage des données reçues en temps réel.
- Envoi de commandes manuelles.
- Enregistrement des communications dans un fichier journal.
- Profils de configuration pour différentes générations de consoles.
- Identification assistée de certaines interfaces UART.
- Premiers outils de lecture et d'analyse des informations Syscon PS3.

## Consoles concernées

- PlayStation 2
- PlayStation 3
- PlayStation 4
- PlayStation 5

La compatibilité dépend du modèle, de la révision de la carte mère et du protocole UART utilisé. Certaines fonctions sont expérimentales et nécessitent des tests sur du matériel réel.

## Compatibilité Windows

Le projet est prévu pour fonctionner sous :
- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11

## Projet communautaire

Ce logiciel a été développé avec l'aide de l'intelligence artificielle.

Je recherche des personnes possédant différentes consoles PS2, PS3, PS4 et PS5 afin de tester le logiciel, vérifier les profils UART et améliorer progressivement les fonctions de diagnostic.

**Tous les retours, tests, corrections et contributions sont les bienvenus !**

## Attention

Avant toute connexion, vérifiez impérativement le brochage UART et les niveaux logiques de votre carte mère. Ne raccordez jamais la broche VCC de l'adaptateur USB-UART à la console sans documentation spécifique.

**Projet en développement – les fonctions expérimentales ne sont pas garanties sur toutes les révisions.**
